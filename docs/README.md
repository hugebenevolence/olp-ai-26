# Preparation guide

Start with **[seven families and fourteen learning notebooks](../notebooks/learning/README.md)**.
Fill each baseline's missing code, reveal its collapsed reference after attempting the block,
then study the advanced method using the same folds and a score/runtime comparison.
All 14 learning notebooks are self-contained: copy one file and configure its data paths;
no repository imports, companion source files, or project installation are needed to run it.
The [blank-notebook playbook](BLANK_NOTEBOOK_PLAYBOOK.md) is the final reconstruction assessment
when prepared code and internet may be unavailable, including the 2k assistant strategy.
The [repo-assisted quickstart](PRACTICE_QUICKSTART.md) creates practice packs and provides an
untimed worked example before you close the repository.

## Recommended practice order

1. Complete the table classification/regression exercises; reconstruct their weakest blocks next day.
2. Learn text multilabel versus single-label output/loss/metric differences.
3. Complete image classification, masks and detection; inspect visual errors and preserve ID order.
4. Study multimodal matching and compare its embedding/extraction cost with a sparse baseline.
5. Finish assistant-free reconstruction, restart recovery and team rehearsal.

The catalog states each template's exact default contract. A completed practice notebook still
needs the organizer's data mapping, permission checks, evaluator, and output specification.
